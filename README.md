# Skrim Music - Веб-приложение для прослушивания музыки

Простой и удобный музыкальный плеер в браузере с возможностью поиска треков.

## Что это такое

Skrim Music - это веб-приложение, которое позволяет просматривать музыкальную библиотеку, искать треки и управлять воспроизведением. Интерфейс интуитивно понятен и похож на популярные музыкальные сервисы.

## Основные возможности

- Просмотр каталога музыкальных треков
- Поиск по названиям и исполнителям  
- Управление воспроизведением
- Современный адаптивный дизайн
- Работает прямо в браузере

## Как использовать

1. Откройте файл `index.html` в браузере
2. Для поиска трека введите запрос в поле поиска
3. Нажмите на любой трек чтобы выбрать его для воспроизведения
4. Используйте кнопки управления для паузы и других действий

## Техническая часть

Приложение построено на чистом JavaScript без внешних зависимостей. Все данные хранятся локально в браузере.
